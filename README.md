# ReHoVa Interiors website

Static website for ReHoVa Interiors Pte Ltd. The public domain is
`https://rehova.sg/`; upload the site files and image folders to the Exabytes
`public_html` directory.

Pages: `index.html`, `about.html`, `services.html`, `gallery.html`, `faq.html`,
`blog.html`, `contact.html`, and `404.html`.

The root also contains `robots.txt`, `sitemap.xml`, and `.htaccess`. Keep the
image folders (`Aquarium/`, `Commercial/`, `Medical & Dental/`, and
`Residential/`) alongside the HTML files.

Before launch:
- Confirm PHP mail delivery is enabled for `contact.php` on Exabytes.
- Review the project images and page text for accuracy.
